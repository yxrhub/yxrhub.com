## 1. 背景与动机

首页当前的视觉呈现明显落后于内容质量,主要原因**不是内容少,而是样式覆盖不全**。

现状证据(基于代码审查):

- `src/components/Welcome.astro` 的 `<style>` 只定义了 `h1` / `h2` / `p` / `code` 四种元素样式,**未定义 `ul` / `li` / `a` / `strong` / `em`**。
- 而 `src/content/index.md` 中大量使用列表与链接:3 个项目条目采用二级嵌套列表,「数字世界的我」一节有 8 个平台链接。
- 结果:项目清单退化为浏览器默认圆点、链接为默认蓝色下划线、段落与列表间距失衡——观感"简陋"。
- `src/layouts/Layout.astro` 仅有 `#container { margin: 16px }`,无内容宽度约束、无排版尺度、无响应式规则。
- `Header.astro`(logo + 登录按钮)与 `Footer.astro`(单行版权)之间没有任何视觉分隔。
- 全站字体栈为通用西文栈,缺少中文优先回退,长段落中文阅读体验一般。

## 2. 目标

在不改变内容信息量的前提下,建立一套完整的视觉与排版系统,使首页达到「个人品牌门面」应有的完成度:层级清晰、留白得体、中文长文可读、移动端可用。
